\section{(a) Pierścień Wielomianów Wielu Zmiennych}

Strukturę danych dla pierścieni wielomianów wielu zmiennych $\mathbb{R}[x_1,\dots,x_n]$ implementuję 
jako mapę \textit{klucz} $\to$ \textit{wartość}, w której kluczem jest wektor wykładników (jednomian bez współczynnika), 
a wartością jest współczynnik zadanego jednomianu. Nieobecne w strukturze klucze (jednomiany) są interpretowane jako mające współczynnik równy zero.
Przykład. Funkcja $f$ (Ćw. 37.) dana wzorem $f=x^3 - x^2\cdot y - x^2 \cdot z$ będzie reprezentowana jako trzy elementy w mapie:
\begin{align*}
\{({\color{red}3}, {\color{green}0}, {\color{blue}0}) \to {\color{darkyellow}1}\}  & \quad (\text{odpowiada } {\color{darkyellow}1} \cdot x^{{\color{red}3}}), \\
\{({\color{red}2}, {\color{green}1}, {\color{blue}0}) \to {\color{darkyellow}-1}\} & \quad (\text{odpowiada } {\color{darkyellow}-1} \cdot x^{{\color{red}2}} \cdot y^{{\color{green}1}}), \\
\{({\color{red}2}, {\color{green}0}, {\color{blue}1}) \to {\color{darkyellow}-1}\} & \quad (\text{odpowiada } {\color{darkyellow}-1} \cdot x^{{\color{red}2}} \cdot z^{{\color{blue}1}}).
\end{align*}
Wielomiany jednej zmiennej można przechowywać w prostszej postaci zwykłej tablicy.
Operacje pierścieniowe ulegają zmianie - część wymaga porządku na jednomianach, który nie jest
potrzebny w przypadku wielomianów jednej zmiennej.

\section{(b) PolynomialReduce, Syzygium, algorytm Buchbergera}

\subsection{PolynomialReduce}

Algorytm \texttt{PolynomialReduce} jest tożsamy z poprzednim sprawozdaniem. 
Jest to algorytm pobierający na wejściu wielomian $f$ oraz ciąg wielomianów $\mathcal{G}=(g_1,\dots,g_n)$. 
Algorytm zwraca ciąg współczynników $(a_1,\dots,a_n)$ oraz wielomian $r$ taki, że:

\begin{align*}
    f = \sum_{i=1}^{n} \alpha_i \cdot g_i + r
\end{align*}

Wykorzystując jeden ze wcześniej zdefiniowanych porządków na jednomianach dokonujemy redukcji wielomianu $f$ względem ciągu $\mathcal{G}$

\begin{enumerate}
    \item Dopóki $f \neq 0$. Znajdź $m=\texttt{LT(f, ord)}$ - największy jednomian $m$ w $f$ według porządku \textit{ord}. \\ Ustal $LC(m)=a$ oraz $LM(m)=M$. (Leading Coefficient oraz Leading Monomial odpowiednio).
    \item Dla każdego $g_i$ w $\mathcal{G}$ znajdź $m_i=\texttt{LT(g\_i, ord)}$, czyli największy jednomian $m_i$ w $g_i$ według \textit{ord}. \\ Ustal $LC(m_i)=b$ oraz $LM(m_i)=N$.
    \item Sprawdź czy $LM(m_i)$ dzieli $LM(m)$. Spełniony musi zostać warunek: $\left(\forall j: LM(m)[j] \geq LM(m_i)[j]\right)$.
    \item Jeśli tak:
    \begin{enumerate}
        \item Wykonaj redukcję: $f := f - \frac{LC(m)}{LC(m_i)} \cdot \frac{LM(m)}{LM(m_i)} \cdot g_i$
        \item Zaktualizuj współczynnik $\alpha_i := \alpha_i + \frac{LC(m)}{LC(m_i)} \cdot \frac{LM(m)}{LM(m_i)}$.
        \item Wróć do kroku 1.
    \end{enumerate}
    \item Jeśli nie, dodaj $LM(m)$ do $r$(eszty) ze współczynnikiem $LC(m)$ i usuń $m$ z $f$. Wróć do kroku 1.
\end{enumerate}

\begin{lstlisting}
Input:  Polynomial f, Sequence of polynomials G = (g_1, ..., g_n), Monomial order ord
Output: Tuple (q, r) where q = (q_1, ..., q_n) and f = sum(q_i * g_i) + r

procedure PolynomialReduce(f, G, ord):
    n := len(G)
    r := empty polynomial
    p := f

    while p is not empty do:
        (lm_p, lc_p) := LT(p, ord)
        divided := false

        for i := 1 to n do:
            if g_i is empty then continue

            (lm_g, lc_g) := LT(g_i, ord)
            
            divisible := true
            for j := 1 to len(lm_p) do:
                if lm_p[j] < lm_g[j] then:
                    divisible := false
                    break
                end if
            end for

            if divisible then:
                q_mon := array of (lm_p[j] - lm_g[j]) for all j
                q_coef := lc_p / lc_g

                q[i][q_mon] := q[i][q_mon] + q_coef

                for each (mon_g, coef_g) in g_i do:
                    new_mon := array of (q_mon[j] + mon_g[j]) for all j
                    p[new_mon] := p[new_mon] - (coef_g * q_coef)
                    
                    if p[new_mon] == 0 then erase new_mon from p
                end for

                divided := true
                break
            end if
        end for

        if not divided then:
            r[lm_p] := r[lm_p] + lc_p
            erase lm_p from p
        end if
    end while

    return (q, r)
\end{lstlisting}

\subsection{Syzygium}

Algorytm wyznaczania Syzygium służy do eliminacji wiodących wyrazów pary wielomianów $f_i$ oraz $f_j$. 
Algorytm przyjmuje na wejściu dwa wielomiany $f_i, f_j$, 
ich najmniejszą wspólną wielokrotność wiodących jednomianów $\text{LCM}(LM(f_i), LM(f_j))$ 
oraz porządek jednomianów \textit{ord}. 
Wynikiem działania jest wielomian $S(f_i, f_j)$ zdefiniowany jako:

\begin{align*}
    S(f_i, f_j) = \frac{\text{LCM}(LM(f_i), LM(f_j))}{LT(f_i)} \cdot f_i \cdot LC(f_j) - \frac{\text{LCM}(LM(f_i), LM(f_j))}{LT(f_j)} \cdot f_j \cdot LC(f_i)
\end{align*}

Algorytm działa w następujących krokach:

\begin{enumerate}
    \item Wyznacz wiodące składniki składnika pierwszego: $LT(f_i) = (lm_i, lc_i)$ oraz składnika drugiego: $LT(f_j) = (lm_j, lc_j)$.
    \item Dla każdego jednomianu $mon$ ze współczynnikiem $coeff$ w wielomianie $f_i$:
    \begin{enumerate}
        \item Oblicz nowy jednomian: $target\_mon := lcm + (mon - lm_i)$ poprzez odpowiednie operacje na wykładnikach.
        \item Dodaj do wynikowego wielomianu wartość $coeff \cdot lc_j$ pod kluczem $target\_mon$.
    \end{enumerate}
    \item Dla każdego jednomianu $mon$ ze współczynnikiem $coeff$ w wielomianie $f_j$:
    \begin{enumerate}
        \item Oblicz nowy jednomian: $target\_mon := lcm + (mon - lm_j)$ poprzez odpowiednie operacje na wykładnikach.
        \item Odejmij od wynikowego wielomianu wartość $coeff \cdot lc_i$ pod kluczem $target\_mon$.
        \item Jeśli współczynnik przy $target\_mon$ wynosi 0, usuń go z wynikowego wielomianu.
    \end{enumerate}
\end{enumerate}

\begin{lstlisting}
Input:  Polynomials fi, fj, Monomial lcm, Monomial order ord
Output: S-polynomial (syzygy)

procedure Syzygy(fi, fj, lcm, ord):
    syzygy := empty polynomial
    (lm_i, lc_i) := LT(fi, ord)
    (lm_j, lc_j) := LT(fj, ord)

    // (LCM / LT(fi)) * fi * lc_j
    for each (mon, coeff) in fi do:
        target_mon := array of (lcm[k] + mon[k] - lm_i[k]) for all k
        syzygy[target_mon] := syzygy[target_mon] + (coeff * lc_j)
    end for

    // (LCM / LT(fj)) * fj * lc_i
    for each (mon, coeff) in fj do:
        target_mon := array of (lcm[k] + mon[k] - lm_j[k]) for all k
        syzygy[target_mon] := syzygy[target_mon] - (coeff * lc_i)
        
        if syzygy[target_mon] == 0 then:
            erase target_mon from syzygy
        end if
    end for

    return syzygy
\end{lstlisting}

\subsection{Algorytm Buchbergera}

Służy do wyznaczania zredukowanej bazy Grobnera dla zadanego ideału generowanego przez skończony zbiór wielomianów $F$.
Algorytm pobiera na wejściu ciąg wielomianów $F$ oraz porządek jednomianów \textit{ord},
 a zwraca zredukowaną bazę Grobnera w postaci ciągu wielomianów $G_{reduced}$.

\begin{enumerate}
    \item Skopiuj wielomiany do bazy $G\gets F$.
    \item Dla wszystkich par $(i,j)$ z $G$ oblicz najmniejszą wspólną wielokrotność wiodących jednomianów i dodaj pary do kolejki.
    \item Wyznacz Syzygium $S_{ij}$ dla każdej pary $(i,j)$ w kolejce.
    \item Zredukuj $S_{ij}$ względem aktualnego zbioru $G$.
    \item Jeśli reszta jest niezerowa, rozszerz zbiór $G$ i dodaj nowe pary do kolejki.
    \item Po sprawdzeniu wszystkich elementów w kolejce, zredukuj $G$ - to wynikowa baza Grobnera.
\end{enumerate}

\begin{lstlisting}
Input:  Sequence of polynomials F, Monomial order ord
Output: Reduced Groebner basis G_reduced

procedure Buchberger(F, ord):
    G := empty sequence
    for each f in F do:
        if f is not empty then append f to G
    end for

    pairs := empty queue
    n := len(G)
    for i := 1 to n do:
        for j := i + 1 to n do:
            push (i, j) to pairs
        end for
    end for

    while pairs is not empty do:
        (i, j) := pop front from pairs
        
        (lm_i, lc_i) := LT(G[i], ord)
        (lm_j, lc_j) := LT(G[j], ord)
        lcm := MonomialLCM(lm_i, lm_j)

        syzygy := SPolynomial(G[i], G[j], lcm, ord)

        if syzygy is empty then continue

        (quotients, remainder) := PolynomialReduce(syzygy, G, ord)

        if remainder is not empty then:
            new_index := len(G)
            for k := 1 to new_index do:
                push (k, new_index) to pairs
            end for
            append remainder to G
        end if
    end while

    reduced_G := empty sequence
    for i := 1 to len(G) do:
        if G[i] is empty then continue

        others := empty sequence
        for j := 1 to len(G) do:
            if i != j and G[j] is not empty then append G[j] to others
        end for

        (quotients, remainder) := PolynomialReduce(G[i], others, ord)

        if remainder is not empty then:
            (lm, lc) := LT(remainder, ord)
            if lc != 1 then:
                monic_remainder := empty polynomial
                for each (mon, coeff) in remainder do:
                    monic_remainder[mon] := coeff / lc
                end for
                remainder := monic_remainder
            end if

            if remainder not in reduced_G then:
                append remainder to reduced_G
            end if
        end if
    end for

    return reduced_G
\end{lstlisting}

\section{(e) Baza Grobnera oraz Trysektrysa}

Dla zadanej funkcji w układzie biegunowym wprowadzamy podstawienie
 $\cos (\theta) = \frac{x}{r}$, tak jak na poprzedniej liście w celu przejścia do układu kartezjańskiego.
\begin{align*}
    r = b \left(4 \cos (\theta) + \frac{1}{\cos (\theta)}\right)
    &= b \left(4 \frac{x}{r} + \frac{r}{x}\right)\\
    b \left(\frac{4x^2 + r^2}{rx}\right) - r &= 0 \\
    b (4x^2 + r^2) - r^2 x &= 0 \\
    b r^2 + 4bx^2 - r^2 x &= 0
\end{align*}
Mamy następujący układ równań:
\begin{align*}
    \begin{cases}
        x^2 + y^2 - r^2 = 0 \\
        b r^2 + 4b x^2 - r^2 x = 0
    \end{cases}
\end{align*}
Wyciągnijmy z pomocą Bazy Grobnera wyrażenia zawierające jedynie $x,y$. Wynik działania programu:

\begin{verbatim}
Grobner basis von -(r^2) + (y^2) + (x^2) und -(r^2)(x) + 7(r^2) + 28(x^2)
Computed Groebner basis:
1. (r^2) - (y^2) - (x^2)
2. (y^2)(x) - 7(y^2) + (x^3) - 35(x^2)
\end{verbatim}
Zauważmy, że drugi element bazy składa się tylko z $x,y$. Jest on zatem naszym rozwiązaniem:
\begin{align*}
    f(x,y) = y^2\cdot x -7y^2 + x^3 - 35x^2 = 0
\end{align*}
